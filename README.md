# Расписание 3333 · ГУАП

Веб-приложение для просмотра расписания занятий группы 3333 ГУАП с современным интерфейсом и гибкими настройками.

## Возможности

### Просмотр расписания
- **Два режима отображения**: список на 2 недели и календарь
- **Фильтрация по неделям**: нечётная, чётная или обе недели
- **Детальная информация о парах**: тип занятия, аудитория, преподаватель, время
- **Схемы аудиторий**: просмотр расположения мест в аудитории
- **Поддержка ВУЦ**: настройка дня недели для военной кафедры

### Настройка внешнего вида
- **4 темы оформления**:
  - Тёмная
  - Светлая
  - Автоматическая (следует за системой)
  - Стекло (с эффектом матового стекла)
- **Акцентные цвета**: 8 вариантов цветовой схемы
- **Цветовые схемы для типов пар**: 4 готовых набора цветов
- **Кастомный фон**: загрузка собственного изображения для темы "Стекло"

### Управление отображением
- **Скрытие пар**: возможность скрыть или затемнить ненужные занятия
- **Предпросмотр**: живой предпросмотр настроек оформления
- **Адаптивный дизайн**: оптимизация для мобильных устройств и десктопа

### Дополнительно
- **Полезные ссылки**: быстрый доступ к ЛК ГУАП и другим ресурсам
- **Оффлайн-режим**: кэширование расписания для работы без интернета
- **PWA**: установка как приложение на устройство

## Технологии

- **Vue.js 3** — реактивный фреймворк
- **Lucide Icons** — иконки
- **Google Apps Script** — бэкенд для загрузки расписания
- **LocalStorage** — хранение настроек и кэша

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/gdxrr/raspisanie_light.git
cd raspisanie_light
```

2. Откройте `index.html` в браузере или разверните на веб-сервере.

## Настройка

Для подключения собственного источника расписания отредактируйте `config.js`:

```javascript
window.SCHEDULE_CONFIG = {
  webAppUrl: 'YOUR_GOOGLE_APPS_SCRIPT_URL',
};
```

## Разработка

Приложение использует чистый JavaScript и не требует сборки. Для разработки достаточно открыть файлы в редакторе и обновлять страницу в браузере.

### Основные компоненты

- **Список расписания** — отображение пар по дням с фильтрацией
- **Календарь** — месячный вид с индикаторами типов занятий
- **Настройки** — панель с вкладками "Расписание" и "Оформление"
- **Модальные окна** — детальная информация о паре
